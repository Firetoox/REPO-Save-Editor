## R.E.P.O.

R.E.P.O. is a game by semiwork. This project is an unofficial fan tool and is not affiliated with,
endorsed or sponsored by semiwork. It contains no game files. Item and cosmetic names in
`lib/catalog.js` and `lib/cosmetics.json` are read from the game so the editor can label the values
stored in save files; all rights to them remain with their owners.
